# Linked Lists in Python

A clean, modular implementation of the Singly Linked List data structure in Python. This repository covers foundational software engineering concepts, memory management logic, and step-by-step methods for linked list manipulation.

---

## 📌 Features & Implemented Methods

The repository includes implementations for key Linked List operations:

| File | Description | Time Complexity |
| :--- | :--- | :--- |
| `linkedlist.py` | Core `Node` and `LinkedList` class definitions | — |
| `append_to_linkedlist.py` | Appends a new node to the end of the list | $O(1)$ |
| `prepend.py` | Inserts a new node at the beginning of the list | $O(1)$ |
| `get_val_at_index.py` | Retrieves node value at a specific index | $O(n)$ |
| `pop_first.py` | Removes and returns the first node (head) | $O(1)$ |
| `pop_ll.py` | Removes and returns the last node (tail) | $O(n)$ |
| `print_method.py` | Utility method to print all node values in sequence | $O(n)$ |
